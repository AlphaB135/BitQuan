## Lessons Learned

- **Pattern**: Audit agents are overly conservative - HIGH severity issues often false positives; always verify code before treating as critical
- **Discovery**: BitQuan consensus code is EXCEPTIONAL quality - no unsafe, no unwrap, deterministic parallel validation with `find_first()`
- **Mistake**: Coinbase maturity should have been implemented earlier - now it's a mainnet blocker (4 hours estimated)
- **Pattern**: IBD header-first approach reduces bandwidth by 99% (validate headers before downloading blocks)
- **Discovery**: Parallel agents reduce audit time by 66% (5 min vs 30 min sequential) - use Haiku for cost efficiency
- **Pattern**: `HashSet::insert()` returns bool - use `if !set.insert(value)` for double-spend detection in one line
- **Discovery**: File permissions 0o600 (owner read/write only) are critical for wallet security on Unix systems
