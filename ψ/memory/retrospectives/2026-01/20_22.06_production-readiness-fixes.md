## Blockers & Resolutions

**Blocker 1**: `target_from_bits` not found in `bitquan_consensus::difficulty`
- **Resolution**: Found it in `bitquan_consensus::pow` module instead

**Blocker 2**: `prev_block_hash` field doesn't exist on BlockHeader
- **Resolution**: Field is actually named `prev_block`

**Blocker 3**: `get_header_at` method doesn't exist
- **Resolution**: Used `get_block_by_height` instead (returns full Block, extract header)

**Blocker 4**: `tip()` returns `Option<BlockHeader>` not hash
- **Resolution**: Extract hash with `header_hash(&header)` if Some
