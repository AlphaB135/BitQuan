# n8n-skills: กุญแจสำคัญที่เปลี่ยน Claude ให้เป็น n8n Expert

## Overview

**n8n-skills** เป็น custom skills สำหรับ Claude AI ที่รวมเอาความรู้เรื่อง n8n ไว้
ทำให้ Claude เข้าใจ Expression Syntax, MCP Tools, Workflow Patterns และสร้าง workflow ที่ซับซ้อนได้ถูกต้อง

## 7 ทักษะสำคัญ (Skills)

1. **Expression Syntax** - รู้จัก expression syntax ของ n8n
2. **MCP Tools** - การใช้งาน MCP tools
3. **Workflow Patterns** - patterns การทำงานของ workflow
4. (และอีก 4 ทักษะ - ต้องดู video เต็มๆ)

## สถาปัตยกรรม 5 Layer (Master Architecture)

- Layer 1-5 ของสถาปัตยกรรมการทำงานร่วมกันระหว่าง AI และ n8n
