# n8n Instance-level MCP: การตั้งค่าและการใช้งานร่วมกับ AI Agents

## Overview

ฟีเจอร์ใหม่ล่าสุดจาก n8n: **Instance-level MCP** - เชื่อมต่อ AI (Claude Desktop) เข้ากับ n8n instance โดยตรง

## ปัญหาที่แก้

ก่อนหน้านี้ถ้าอยากให้ AI ช่วยรันงานใน n8n ต้อง:
- Copy JSON code ยาวเหยียดไปมา
- ไม่สามารถสื่อสารกับ n8n ได้โดยตรง

## วิธีแก้

Instance-level MCP ทำให้:
- AI สามารถสั่งรัน workflow ได้โดยตรง
- อ่านผลลัพธ์จาก n8n ได้เลย
- แก้ไข workflow ผ่าน AI ได้
- ไม่ต้อง copy JSON อีกต่อไป

## Key Features

- เชื่อมต่อ Claude Desktop กับ n8n โดยตรง
- AI เข้าใจโครงสร้าง n8n workflow
- รัน/แก้/สร้าง workflow ผ่าน conversation
